## 🚀 Featured Projects

### 💡 Low-Light Image Enhancement on FPGA
**FPGA | Image Processing | Verilog HDL | Retinex Algorithm**

Designed and implemented FPGA-based low-light image enhancement architecture using Verilog HDL with Retinex algorithm. Developed RTL modules for illumination-reflectance separation and verified functionality through simulation and FPGA testing.

---

### 🔌 UART Transmitter and Receiver
**Digital Design | Verilog | RTL | Serial Communication**

Implemented full-duplex UART communication modules with configurable baud rates. Designed and tested transmitter and receiver blocks with proper handshaking and error detection.

---

### 🧮 32-Bit ALU Design
**Arithmetic Logic Unit | Verilog | Digital Logic**

Designed a comprehensive 32-bit ALU supporting multiple arithmetic and logical operations. Implemented with optimized gate-level logic and verified through ModelSim simulation.

---

### 🏗️ RISC Processor Design
**Processor Design | RTL | Verilog | Digital Architecture**

Built a simplified RISC processor architecture with instruction fetch, decode, execute, and memory stages. Implemented complete datapath and control logic with RTL verification.

---

### 🔋 Smart Energy Meter (Embedded Systems & IoT)
**IoT | Embedded C | Microcontroller | Real-Time Data Acquisition**

Developed IoT-based smart energy monitoring system with microcontroller interfacing and real-time power measurement. Implemented sensor data acquisition and embedded firmware for processing and communication.


---

### 🎛️ Voltage Regulator PCB Design
**PCB Design | Eagle | Hardware Design | Circuit Design**

Designed schematic and PCB layout for voltage regulator circuit using Eagle PCB. Performed component placement, routing, and PCB verification for reliable power delivery.
